封存测试集The sealed test split

val 分数被 agent 看了上百次，可能被选择偏差抬高。所以在运行结束后，把基线和 agent 的方法各用两个 seed 重新量化，同时在 val 和 agent 从未见过分数的 test 上打分。“停下时的方法”是 agent 被打断那一刻工作目录里的方法；“val 最好提交”是它所有提交里 val 最低的那个。The agent read validation scores hundreds of times, so they may be inflated by selection. After a run, the baselines and the agent's method are quantized again on two seeds and scored on val and on a test split whose scores the agent never saw. “Method when it stopped” is what the working directory held when the agent was interrupted; “best-val submission” is the lowest val S among all its submissions.

没参与调参的任务Tasks nobody tuned on

This section asks a different question: can the quantized model still do tasks? These tasks (math, instruction following, code, multiple-choice knowledge, and KL on code and on text in six languages) took no part in the agent's search, and the agent never saw their scores.
